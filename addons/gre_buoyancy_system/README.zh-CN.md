# Buoyancy System（浮力系统）

[English](README.md) · **简体中文**

让 `RigidBody3D` 浮在水面上。它追求看起来对，而不是物理上精确：物体以你设定的深度水平
地浮着，随波起伏摇晃，和泡沫一起顺风漂移，在水中减速。只需一个设置 `draft` 来决定它的
位置，没有体积或密度需要调。

需要 `gre_core`，以及注册了 `GREWaterSurface` 的水面（例如 `gre_ocean_system`）。

## 工作原理

- **探针。** `GREBuoyantBody` 在刚体碰撞形状的俯视轮廓上铺一组网格探针，位于船体的
  水线平面上（比最低点高 `draft`）。每个物理帧它把所有探针作为一次水面查询提交（见
  `gre_core` 的 `GREWaterSurface`），并使用最新的结果，外推到当前时刻。
- **浮力。** 每个探针托起它那份重量的 `1 + 深度 / draft` 倍，最多到船体的全高。因此在
  平静水面上，无论质量多大，船体最低点都恰好静止在水面下 `draft` 处；它大约每
  2π√(draft / g) 秒起伏一次：0.3 米时 1.1 秒，战列舰的 9 米时 6 秒。各探针的份额围绕
  质心平衡，所以无论质心在哪里（只要在船体轮廓内），物体都水平地浮着。
- **天生不倾覆。** 浮力的作用点从不低于质心，所以质心高也不会让物体翻覆；质心低
  （压舱物，例如演示中的浮标）则让它更稳。
- **阻尼和阻力**都相对于水计算。垂直阻尼对抗的是水面自身的起落（`damping_ratio`），
  所以物体随波起伏，而不是和波浪对抗。沿船体和横向的阻力对抗的是表层水的速度：波浪的
  运动加上表层漂流（`GREWaterSurface.get_surface_drift()`，海洋上为风速的 3%）。漂浮物
  和泡沫一起顺风漂移；`sideways_drag` 大于 `forward_drag` 的船体会沿船头方向前进。
- **尾迹。** 物体每个物理帧还会向水面报告自己的船体：它的轮廓（来自碰撞形状）、在
  周围水面下的深度，以及它下方水的运动。海洋画出它相对于水的运动激起的波浪：尾迹、
  船首波、上下起伏时的环形波，以及它的速度搅起的泡沫（`wake_strength` 同时调整两者）。
- **随尾迹起伏（可选）。** 默认情况下物体只读取水面模拟的海浪，从不读取物体搅起的
  波浪，所以它的动作不会反过来影响自身的运动。`wave_response` 大于 0 时，它也会感受
  这些波浪：大船的尾迹经过时木箱会摇晃，小船穿过自己的尾迹时会起伏。在它自己的轮廓
  内，水面取自船体周围的一圈边缘（沿运动方向向后拉长），所以它自己排开的水（身下的
  隆起和身后留下的凹坑）从不托起或压低它。只在相机附近有效，海洋只在那里模拟这些波浪。
- **启动。** 在收到第一个水面采样（几帧）之前，物体保持冻结，之后才释放。

## 使用方法

```
RigidBody3D            mass, center_of_mass, not frozen
├─ CollisionShape3D    box, sphere, capsule, cylinder, convex or concave polygon
└─ GREBuoyantBody
```

1. 在 `RigidBody3D` 下添加一个 `GREBuoyantBody` 子节点，船头朝 −Z。
2. 设置 `draft`：平静水面上船体最低点的深度。
3. 设置阻力：船体用较低的 `forward_drag` 和较高的 `sideways_drag`，漂浮杂物两者大致
   相等。
4. 运行。打开 `debug_enabled` 可以看到探针和每个探针上方的水面。

| 设置 | 含义 |
| --- | --- |
| `draft` | 静止时船体最低点的深度（米）；也决定起伏的快慢。 |
| `probe_grid` | 横向 × 纵向的探针数；0 表示按船体比例自动选择（约 16 个）。探针越多，长船体下的波浪跟随得越准。 |
| `damping_ratio` | 0 时不停起伏，1 时稳定下来且不过冲。 |
| `forward_drag`、`sideways_drag` | 水沿船体和横向带走速度的快慢（1/秒）。 |
| `wake_strength` | 调整物体激起的波浪和泡沫（1 为它的运动实际激起的大小，0 为没有）。 |
| `wave_response` | 物体对物体激起的波浪（包括它自己的）的感受程度（0 为完全不感受，默认值；1 为完全感受）。 |

- 碰撞形状决定探针的位置，它们的高度决定物体最多能被压入水中多深。只参与碰撞、
  不参与浮力的 `CollisionShape3D`（座位、桅杆）放进 `buoyancy_ignore` 组
  （`GREBuoyantBody.IGNORE_GROUP`）。通过 shape-owner API 而不是作为 `CollisionShape3D`
  子节点加入的形状从不计入。
- Godot 刚体自身的阻尼（项目设置 > 物理 > 3D > Default Linear Damp，0.1/秒）会叠加到
  阻力上。把刚体的 `linear_damp_mode` 设为 **Replace** 即可只保留水的阻力（船只模板就
  是这样设置的）。
- 代码中：`is_in_water()`，以及 `get_point_depth(global_point)` 获取物体上某点的深度
  （例如螺旋桨；收到第一个采样前为 −INF）。
- 场景面板会对以下情况给出警告：刚体被冻结、缺少或不支持的碰撞形状、`draft` 比船体还深、
  质心在船体之外。

## 限制

- 只有 `wave_response` 大于 0 时，物体才会感受物体激起的波浪，而且只在相机附近
  （海洋只在那里模拟这些波浪）：离得更远时，它们只随海浪漂浮。
- 水面把船体轮廓看作一个拟合碰撞形状轮廓的超椭圆（尖船头会变得更圆）。
- 物体不会翻覆、进水或沉没，并且无论载重如何都水平地浮着。
- 暂时还没有水花。
